# Changelog

## 0.1.0 (November 23, 2026)

First release.

- Virtual machines: order by plan code and city or by plan ID, power, tags, firewall, reinstall, delete (`virtual_machine`),
  snapshots, backups and additional IPv4 addresses.
- DNS: zones with DNSSEC, record sets, geo-routed records.
- Firewall: rulesets with ordered rules, address groups.
- Access: SSH keys, custom roles, role assignments, groups, secrets, environment variables.
- Game servers: order, power, startup variables, container image, game change, backups, databases.
- Marketplace and account information: offers, plan codes, regions, providers, add-ons, distros, instant apps, credit and subscriptions.
- `noderings` inventory plugin.
